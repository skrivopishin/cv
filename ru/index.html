Финтех — P2P-платформа инвестиций и кредитования

Lead DevSecOps Engineer, SoftTeco ноябрь 2023 – сейчас

Отвечаю за инфраструктуру регулируемой финтех-платформы: три AWS-аккаунта, три EKS-кластера, всё описано в Terraform и доставляется через GitOps. Руковожу небольшой DevOps-командой и каждый день работаю с продуктовыми разработчиками.

Платформа

  • Построил и сопровождаю EKS-кластеры для stage, production и общего аккаунта инструментов, обновляю их вплоть до версии 1.34.
  • Автомасштабирование на Karpenter со spot- и выделенными пулами нод; KEDA для событийных нагрузок.
  • Заменил ingress-nginx на Gateway API с Istio и Envoy, затем полностью вывел nginx из работы.

Инфраструктура как код

  • Внедрил Crossplane в дополнение к Terraform: Terraform для фундамента, Crossplane Compositions для ресурсов, которые живут вместе с приложением.
  • Отрефакторил все Terraform-модули под современные задачи в библиотеку примерно из 55 модулей с релизами по тегам: EKS, RDS, DMS, сети, Cognito, SSO, Lambda и другие.
  • 13 собственных Helm-чартов, публикуются как OCI-артефакты через semantic-release.
  • Секреты как код: манифесты по окружениям в AWS Secrets Manager и KMS, синхронизация через External Secrets Operator.

CI/CD

  • Перевёл компанию с GitLab на GitHub: все репозитории и пайплайны.
  • Self-hosted раннеры GitHub Actions в Kubernetes (ARC) плюс автомасштабируемый парк EC2.
  • Библиотека из 23 переиспользуемых composite actions: сборки Nx affected, матрицы деплоя, релизы образов, кеширование, e2e-отчёты.
  • Сканирование безопасности, ревью по CODEOWNERS и AI-ревью pull request'ов в CI.

Самообслуживание для разработчиков

  • Сделал автоматизацию, с которой разработчики сами выполняют большинство операций без DevOps: создают новое приложение, поднимают окружение, выпускают релиз, добавляют IP в allowlist, запускают базу.
  • Preview-окружения по запросу через Crossplane Compositions и ArgoCD ApplicationSets.
  • Заменил документ в Google Docs на портал документации, который пишется в git и публикуется автоматически.

Наблюдаемость

  • Перешёл с Prometheus, Thanos, Loki и Grafana на SigNoz с автоинструментированием OpenTelemetry.
  • Алерты и дашборды описаны в Terraform.
  • Ежедневный отчёт о здоровье production, который генерирует LLM на Bedrock через MCP-сервер поверх телеметрии.

Данные и безопасность

  • Перенёс основную базу с MS SQL на PostgreSQL через AWS DMS.
  • Партиционирование таблиц на pg_partman и pg_cron с архивированием в S3.
  • Dual-stack VPC с IPv6, Transit Gateway и site-to-site VPN, WAF allowlist, реакция на вредоносные файлы через GuardDuty, CloudTrail и flow logs.

AI-инфраструктура

  • Строю внутреннюю платформу для агентов: шлюз LiteLLM к Bedrock, Hatchet, изолированные раннеры в Kubernetes для coding-агентов.
  • Развернул корпоративный AI-поиск по знаниям компании.
